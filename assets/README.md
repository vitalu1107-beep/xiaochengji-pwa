# 视觉资产

森林插画由内置 imagegen 基于用户确认的五页视觉稿及长毛三花参考生成，仅包含插画，无 UI 字体。输出转为 WebP，五张合计约 835 KB。原图在本地工作区 implementation-assets/ 保留。

图标来源：Phosphor Icons core regular / fill（https://github.com/phosphor-icons/core/tree/main/assets/regular），MIT 许可见 icons/LICENSE。caret-right 以 chevron-right 命名保存；仅将 currentColor 固定为暖白，未改路径。

生成提示：保留原森林场景、配色、笔触及同一只长毛三花，去除全部 UI、文字、图标、边框和水印；左侧留 HTML 标题空间，猫小且唯一，底部自然融入 #083D2F。首页为圆眼坐姿，记录页安静趴卧，成就墙散步，回顾页林间溪水边看光，设置页树根洞内睡觉。
