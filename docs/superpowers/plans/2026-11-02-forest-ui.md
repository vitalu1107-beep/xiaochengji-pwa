# 小成就森林 UI 落地计划

视觉依据：用户在本轮附上的五张定稿；首页使用圆眼长毛三花修订版。目标为更新原 GitHub Pages 产品，并随时可切回旧界面。

1. 保留基线 ebbf0b528c8deac697cb816149ae08c795cfea38 的 Git 备份分支，并保存同源 legacy 页面。
2. 保持原静态 PWA 技术栈和 localStorage 数据格式，实现五页真实文字、表单、细线分组和森林插画。
3. 保留并验证原记录、心情、标签联想、搜索、详情、删除、随机回顾、昵称、安装、复制功能。对存储失败与输入法误提交做必要保护。
4. 新版 Service Worker 原子缓存并支持新旧版离线互切，更新不触碰用户记录。
5. 运行有意义的功能/缓存测试；本地浏览器检查五页、窄屏和操作流程；保存 design-qa.md 和截图。
6. 检查远程 main 未发生并发变化后发布；验证 Pages 部署与线上页面，记录回滚说明。

实现分工：root 负责 HTML/CSS/图标整合与浏览器、发布；runtime_data 负责 main.js/功能测试；rollback_sw 负责 legacy/SW/manifest/回滚说明及测试；资产代理制作五张无字插画。
